## Featured: Agent Role Contracts (ARC)

**Catch out-of-scope coding-agent tasks, declared self-review, and stale handoffs before dispatch.**

[ARC](https://github.com/suirindo/agent-role-contracts) is an MIT-licensed, model-agnostic Node.js CLI. It checks supplied role, write-scope, reviewer and handoff declarations offline. Your runtime remains responsible for actual permissions and execution.

[Try the three-minute demo](https://github.com/suirindo/agent-role-contracts#quick-start--three-minutes) · [Share a one-line problem or comment](https://github.com/suirindo/agent-role-contracts/issues/37) · [Star ARC if useful](https://github.com/suirindo/agent-role-contracts)
